# Integrations

The **Integrations** directory contains services that connect Techibbie to external platforms and third-party APIs.

| Integration                       | Description                                      |
| --------------------------------- | ------------------------------------------------ |
| [`discord/`](./discord/README.md) | Discord bot and webhook integration              |
| [`tiktok/`](./tiktok/README.md)   | TikTok API integration for content and user data |
| [`twitch/`](./twitch/README.md)   | Twitch EventSub and API integration              |
